# Универсальный эталонный шаблон (generic reference template)

Каркас, нейтральный к фреймворку (framework-neutral), для адаптации выбранного
шаблона экранного UI. Заменяйте слоты и подписи только после подтверждения
спецификации экрана и матрицы областей отображения (viewport matrix) проекта.

- Статус: `reference-only`
- Только тестовые данные-заглушки (fixture data)
- Нет API проекта, секретов или боевых данных (production data)
- Включены восстановление с клавиатуры и хуки статуса/ошибки для доступности
