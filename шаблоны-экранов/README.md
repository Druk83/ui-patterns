# Переиспользуемые шаблоны экранного UI (reusable screen UI templates)

Каталог содержит универсальные каркасы, нейтральные к фреймворку
(framework-neutral), для шаблонов экранного UI и живых эталонных прототипов
(live reference prototypes). Он не содержит боевой интерфейс (production UI)
или экраны конкретного проекта.

Каждый шаблон содержит `ID`, версию, совместимые паттерны, обязательные входные
данные, слоты компонентов, состояния, действия, переходы, контракт области
отображения (viewport contract),
хуки доступности и прототип только для reference (reference-only).

Каноническая среда выполнения — HTML/CSS/JS, нейтральная к фреймворку.
Прототипы запускаются локально с тестовыми данными-заглушками (fixture data) и
не требуют API проекта.

Для каждого из 13 зарегистрированных экранных шаблонов в `manifest.json` указан отдельный `template_path`
с запускаемым `index.html`; общие CSS/JS и контракт находятся в `эталонный-шаблон/`.

Для списков доступны отдельные экранные эталоны табличного представления и карточной ленты. Выбор между ними выполняется по структуре данных и задаче пользователя, а не по одному визуальному предпочтению.

## Публичный каталог

- `manifest.json` — машиночитаемый каталог шаблонов;
- `контракт-пула-экранов.yml` — контракт machine-readable screen pool проекта-потребителя;
- `эталонный-шаблон/` — общий каркас HTML/CSS/JS для адаптации;
- `контракт-шаблона.md` — контракт входных данных, результата и проверки.
- `эталонный-шаблон/визуальный-базис.json` — состав runtime и visual проверок.

- Проекты-потребители выбирают шаблон только после подтверждения пула экранов
  (screen pool) и матрицы областей отображения (viewport matrix).
- Пул экранов принадлежит проекту-потребителю: каталог публикует его контракт и
  validator, но не добавляет в себя продуктовые экраны и размеры устройств.
